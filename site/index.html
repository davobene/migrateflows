Converts automatically

  • Node.js code steps, including steps.X.$return_value, $.export, $.flow.exit, $.respond and axios from @pipedream/platform
  • Props with {{ }} expressions, environment variables and data stores
  • HTTP and schedule triggers (from the official export)
  • Pre-built actions for the services listed here, using your own n8n credentials

Needs a quick check

  • Python steps (beta)
  • Email and app event triggers: pick the matching n8n trigger
  • npm packages: allowed on self-hosted n8n, not on n8n Cloud
  • Actions not on the list stop with a clear error until you replace them
