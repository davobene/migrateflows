Questions

Can I keep running Flowise?

Your instance keeps working, but the project is archived: no new releases, no security patches and no support. Any new vulnerability stays open.

Do I need to re-upload my documents?

Not if they are in a hosted vector store such as Pinecone, Qdrant, Supabase or Postgres: the n8n workflow reads the same index, as long as you keep the same embeddings model. In-memory and FAISS stores are rebuilt with the loading workflow we generate.

Why n8n?

n8n has the same LangChain building blocks as Flowise (agents, chains, memory, vector stores, tools) plus hundreds of app integrations, and it is actively maintained, self-hosted or in the cloud.

MigrateFlows is an independent tool, not affiliated with FlowiseAI, Workday or n8n. Free during beta.
