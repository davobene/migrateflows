Questions

What does OpenAI offer instead?

Two paths: keep the exported Agents SDK code and run it yourself, or rebuild the workflow as a ChatGPT workspace agent (Business, Enterprise and Edu plans). Neither keeps a visual editor you can host.

Will my vector stores and web search still work?

Yes. n8n's OpenAI chat model supports OpenAI's built-in web search, file search and code interpreter, so the converted agents use the same vector store IDs with your OpenAI API key.

What about ChatKit?

ChatKit itself is not being shut down, but it needs a backend. n8n's chat trigger gives you a hosted chat page and a webhook you can call from your own front end.
